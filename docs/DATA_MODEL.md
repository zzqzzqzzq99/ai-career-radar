# 岗位数据与复刻说明

## 三种记录

1. **自动发现**：程序从公开招聘接口或无需登录的搜索结果提取标题、机构、地点和原始链接。它只证明发现了页面。
2. **研究记录**：维护者阅读原始页面后，记录地点资格、合同类型、门槛、适配理由、缺口和下一步。每条必须保留核对日期。
3. **机构观察与排除**：前者是值得持续查看的招聘入口，不代表存在空缺；后者保留容易误判但当前不适用的机会及证据。

## Remote 的处理

Remote 是工作方式，不是地区资格。页面必须进一步说明候选人可以在哪个国家或地区居住、签约和收款。若列表地点与岗位正文冲突，统一标为“待确认”；若官方资格规则排除某地区，标为“不适用”。

## 如何改成自己的看板

1. 修改 `app/public-opportunities.json` 中的研究记录与 `audiences`。
2. 在 `scripts/refresh-global.mjs` 中替换或增加具有公开接口的数据源，并为新格式补解析测试。
3. 在 `scripts/refresh-jobs.mjs` 中修改中文检索词。若目标网站需要登录、验证码或绕过访问限制，不把它接入自动采集。
4. 修改 `vite.pages.config.ts` 的 `base`、`package.json` 的仓库信息及页面元信息。
5. 运行 `npm test`。部署后再核对原始链接、定时任务和页面时间。

## 贡献数据

新增岗位应包含机构、标题、原始HTTPS链接、发现与核对日期、地点原文、合作形式和最多三个能力标签。摘要使用转述，不复制完整职位描述；不提交简历、联系方式、Cookie、令牌或求职记录。
